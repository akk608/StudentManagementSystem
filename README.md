## About
A web-based Student Management System built with ASP.NET Web Forms, C#, and SQL Server.

## Features
- Manage Students (Add, Edit, Delete, Search)
- Manage Courses (Add, Edit, Delete)
- Manage Enrolments (Enrol, View, Remove)
- Manage Grades (Add, Edit, Delete)

## Tech Stack
- ASP.NET Web Forms
- C#
- SQL Server
- ADO.NET Connected Mode

## Setup Instructions
1. Run DatabaseSetup.sql in SSMS
2. Open StudentManagementSystem.sln in Visual Studio
3. Press F5 to run
